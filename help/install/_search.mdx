## Adding the search bar

To add Intelligent Search as well, paste this snippet in the same place:

```html
<script
  id="xapp-search-js"
  src="https://search.xapp.ai/xapp-search-bar.js?key=YOUR_SEARCH_KEY"
></script>
```

The search bar also needs a button on your site to open it. See [Triggering search with a button press](/help/channels/intelligent-search#triggering-search-with-a-button-press) and [How to find the Intelligent Search key](/help/channels/intelligent-search#finding-code-snippet--key).
