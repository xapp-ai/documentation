# Add the website widget to Duda

## Before you start

- You need access to your Duda site editor.

## Steps

1. Open your site in the Duda editor.

2. Click `Widgets` on the left side.

3. Search for `HTML` and drag the HTML widget onto your page.

4. In the HTML Content panel, paste the code below:

   ```html
   {{snippet}}
   ```

5. Click `Update` to close the HTML Content panel.

6. Click `Republish` to update your live site.

## Check it worked

Visit your live site. The widget button should appear at the bottom of the page. It can take a few minutes to show up; if you don't see it, clear your browser cache or open the site in a private window.

## Troubleshooting

- **Widget not appearing**: make sure you clicked `Update` and then `Republish`.
- **Still nothing**: check that the code was pasted exactly as provided, then open your browser's developer console and look for script errors.
