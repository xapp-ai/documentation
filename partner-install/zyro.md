## Steps

2. Click `Website settings`, then `Integrations`.

3. Paste the code below into the `Custom code` section:

   ```html
   {{snippet}}
   ```

4. Save, then publish your site so the change goes live.

## Check it worked

Visit your live site. The widget button should appear on the page. It can take a few minutes to show up; if you don't see it, clear your browser cache or open the site in a private window.

## Troubleshooting

- **Widget not appearing**: make sure the code was saved in `Custom code` and that you published the site.
- **Still nothing**: open your browser's developer console and look for script errors on the page.
